## 一、任务定位

- **目标**：在不改变外部行为的前提下，重构代码结构，使项目可长期维护。
- **非目标（明确不做）**：
  - 不追求新功能、不改 UI 视觉风格、不改交互逻辑（导航/动效/双形态语义保持现状）。
  - 不重写 GPT-SoVITS 本体、AIRI 本体（它们都是上游外部组件）。
  - 不删除任何运行依赖文件（ launcher/、voice/、llm_guard.py、start-voice.bat、assets/ 均受保护）。
- **成功标准**：§8 的验收清单全部通过；代码结构从"两个上帝文件"变为"按职责分层的模块"，且每一处重构都有对应的验证证据（编译输出、截图、功能检查记录），而不是"看着差不多"。

## 二、项目速览（现状 v1.3，已发布）

**系统链路**（端口固定，勿改）：

```
furina.exe 启动器（C# WinForms）
   ├─ NewAPI 网关（可选，:3000，密钥托管与模型转发）
   ├─ LLM 守卫（:3001，llm_guard.py，仅标准库）
   ├─ AIRI 桌面宠物（意识模块 API 必须指向 :3001，不是 :3000）
   ├─ 语音适配器（:9881，voice/openai_tts_adapter.py，仅标准库）
   └─ GPT-SoVITS 语音服务（:9880，外部组件）
```

- 适配器把 AIRI 的 OpenAI TTS 请求翻译为 SoVITS api_v2 请求；守卫做 1000 字前置检查（超限打回重生成）+ ACT 情绪分段，与适配器共享 ACT 信息做情绪同源选音。
- 启动器负责：图形化配置（组件路径逐项校验）、一键启停、五组件状态灯、探活看门狗（掉线重拉）、启动画面与四章内置教程。
- 看门狗节奏：语音服务快速通道 5s（连续 2 次拒绝连接立即重拉，超时且 CPU 精确为 0 才判卡死），NewAPI/守卫慢速通道 15s（阈值 `FailRestartThreshold`，默认 3）。
- 用户自定义行为：AIRI 关闭时自动退出并回收 / 退出时保留服务运行（二选一互斥）。停止点击后立即切回荒形态（乐观切换），就绪等待循环每 2 秒检查停止信号。

**版本**：v1.3 已发布于 <https://github.com/Bob-Heng/furina-airi/releases/tag/v1.3>。本仓库无其他协作者。

## 四、技术债清单（重构动机，按严重度）

1. **上帝文件**：furina_gui.cs ≈ 2950 行，入口/主题/控件/页面/过渡/自检/启动画面全部混在一起；furina.cs ≈ 944 行，配置/进程/探活/回收/调度混置。改一行需要全文搜索，回归风险大。
2. **重复与近重复**：四张"组件二级配置页"由同一个 BuildComponentDetail 生成，字段创建/浏览/校验/标记分布在三处（BuildComponentDetail、ValidateAll、HookTextChanged、FieldsFrom/ToCfg），职责交叉。
3. **隐式时序依赖**：MainForm 构造里 BuildNav→BuildPages→ApplyDpiScale→HookTextChanged→FieldsFromCfg→ValidateAll 的顺序是隐性契约（二级页必须预先构建，文本框才能存在），新人极易踩雷。
4. **绘制与过渡的状态机散落**：Navigate、ComponentsPage.OpenDetail/CloseDetail、SwitchTheme、FadeOverlay 各自管理过渡生命周期（activeTr 收尾），同类逻辑两份。
5. **无自动化测试**：目前唯一验证手段是编译 + selfshot 截图 + 人工点击。重构必须先建立"可重复验证"的最小闭环，否则高速重构必然引入静默回归。
6. **配置与密钥管理**：furina.ini 的键值协议没有集中定义（字段散落在 Cfg 类/读/写/界面四处）。

## 五、重构总原则（按生成式软件工程规范）

1. **先规格后编码**：每个切片先写验收标准（§8 已给底稿，可细化），再实现。禁止"重构完全部再测"。
2. **行为保持**：外部可观察行为（端口、协议、ini 键名、界面视觉与动效、启停时序、看门狗节奏、停止响应时间）一律不变。这是重构，不是改版。
3. **垂直切片**：每片都能独立编译、独立验证、独立回滚（`git revert <commit>`）。
4. **证据优先**：每片交付必须附：改动文件清单、编译输出、selfshot 截图对比、功能检查记录、未验证项与风险。禁止只说"已完成"。
5. **ADR 记录**：凡结构决策（拆不拆、怎么拆、命名、依赖方向）记入 `docs/decisions.md`（新建，格式：背景/备选/决策/后果）。
6. **小步提交**：每片一个 commit；任何一片未通过验收不得进入下一片。
7. **流程沉淀**：遇到同类坑第二次出现，必须转化为规则/检查/文档（写进本文件 §9 或 AGENTS.md 或自检脚本），而不是再次提醒。

## 九、实现陷阱清单（本项目踩过的坑，禁止回退）

**WinForms / 绘制**
- 后 Add 的控件先 Dock（navRail 必须最后 Add 才能停在左侧）。
- 自绘控件透明背景必须 `SetStyle(SupportsTransparentBackColor, true)`。
- 所有自绘 OnPaint/OnPaintBackground 必须先判 `Width <= 0 || Height <= 0`（最小化时为零尺寸，LinearGradientBrush 会抛异常）。
- 一个控件只能有一个父容器（状态灯实例不能跨页共享；用 AllPills 注册表统一刷新）。
- 页面过渡一律用**快照过渡（WM_PRINT/DrawToBitmap）**，禁止逐帧移动 HWND（残影）。**禁止用 CopyFromScreen 截页面过渡图**（DWM 会采到混合半成品帧）；屏幕直采只允许用于窗体级主题切换快照（那个修的是标题栏偏移）。
- 新过渡开始前必须强制收场在播过渡（ComponentsPage.ForceFinishTr 与 MainForm.activeTr 同款语义），否则快速连点叠中叠。
- PrivateFontCollection 必须常驻存活，取出 FontFamily 后 dispose 集合会使其句柄失效。
- 控件 BackColor 为透明色时，其子控件取样父级 PaintBackground 的返回值；主页背景必须是帧缓冲整图（渐变+场景+文案一体），否则圆角控件四角与场景不一致。
- 原生 TextBox/RichTextBox 只能用已注册字体：通过 `AddFontResourceEx(FR_PRIVATE)` 让私有字体对原生控件生效。

**运行时**
- 停止链路：`WaitForProbe` 每轮都要检查停止信号（曾导致停止延迟十几秒）；停止点击是乐观切主题（立即回荒形态）。
- 看门狗"超时"≠死亡：只有拒绝连接，或超时且 CPU 精确为 0 才重拉（防止误杀正在合成的服务）。
- 全局异常改为静默记日志（Application.ThreadException），不弹"未处理异常"对话框。
- 配置改动为 400ms 防抖自动保存，无"保存"按钮；行为两项互斥。
- AIRI 意识模块 API 必须指向 **:3001（LLM 守卫）**，不是 :3000。

**素材与版权红线**
- `SDK_SC_Web.ttf`（汉仪商业字体）**绝不提交、不打包进 exe**：运行时仅从本机原神目录读取或 `launcher/fonts/` 私有副本；分发兜底是 exe 内嵌得意黑（OFL 1.1，可捆绑，`launcher/fonts/OFL.txt` 必须随附）。
- 官方 CG/游戏原声解包素材不入库（`.gitignore` 已含 `*.jpg`、`assets/models/`、`assets/motions/`、`voice/refs|slice_in|sliced`）。剪影图标与 furina-silhouette.png 为用户提供的素材，可入库。
- 教程文本不要写"解包游戏原声"，只写自行录制/授权获取参考音。

**密钥**
- `launcher/furina.ini` 含本机路径与网关密钥，**永不提交**（.gitignore 已覆盖）；示例配置只改 `furina.ini.example`。
- 截图/日志外发前检查是否含密钥（网关密钥字段在"NewAPI 网关"二级页）。
