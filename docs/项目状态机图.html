芙宁娜项目 · 运行状态机

AIRI（意识/舞台）＋ NewAPI 网关（3000）＋ DeepSeek ＋ TTS 适配器（9881）＋ GPT-SoVITS（9880）

A · 启动层每次开机：Startup 文件夹 VBS → start-voice.bat
关机 / 未启动 开机自启→ 探测端口curl 9880 / 9881，超时即死 存活 → 跳过→ 就绪待命等 AIRI 连接
探测端口 无响应→ 清理残留进程taskkill 占口 PID → 拉起服务SoVITS ＋ 适配器 → 模型加载权重上卡，约 1 分钟 → 就绪待命

自愈合环：运行中崩溃 → 下次手动跑 bat 或重启电脑 → 回到「探测端口」。首句合成约 19 s（冷启动建会话），之后热机约 4 s/句。

B · 对话层AIRI 内的一轮对话
空闲 你开口→ LLM 生成网关 :3000 → DeepSeek，角色卡 v2.2 约束 流式回复→ 解析舞台指令ACT → 表情/动作；按句号断句 → 逐句请求语音POST :9881/v1/audio/speech → 排队播放你听到她说话 播完→ 空闲
C · 语音适配器每一句话的合成决策（对话层每句都走一遍）
接收请求 → 清洗文本剥舞台残留、边缘标点、孤悬破折号 纯标点/空→ 0.3 s 静默不送合成，防怪声 → 返回
清洗后文本 ≤5 字→ 短句规则固定清晰参考音，防气声塌缩 → 合成
清洗后文本 普通句→ 情绪判定soft / calm / bright 信号词 → 选参考音15 s 粘性窗口内沿用，否则轮换（跳过黑名单） → SoVITS 合成POST :9880/tts
合成结果 失败（如参考音超 10 s 被 400）→ 拉黑该参考音进程级，重启复位 → 兜底参考音重试 再失败→ 502该句无声（设计上的最后兜底）
合成成功 时长 < 0.2 s/字→ 疑似塌成气声 → 兜底重试
合成成功且时长正常 → 补静默头 0.10 s ＋ 尾 0.28 s，句间气口 → 返回 wav → AIRI 播放
D · 参考音生命周期8 条平静语音组成的轮换池（ref_pool.json）
池中的参考音 启动校验：时长 3~10 s→ 在役轮换 ⇄ 粘性占用同一轮对话 15 s 内复用，防一句一个腔调 → 回池
池中参考音 时长越界→ 启动即剔除并写日志 →→ 在役参考音 合成失败一次→ 进程级拉黑重启适配器后复位重审
普通状态 就绪 / 成功路径 降级 / 重试 故障终点 虚线框 = 起止状态
